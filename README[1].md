# SafeCredit

**P2P Lending Platform using Machine Learning and Explainable AI**

SafeCredit is an academic Software Engineering team project focused on a P2P lending platform prototype. The project combines a web interface, a FastAPI REST API, and machine-learning-based credit risk assessment.

## Main Features

- Safe-Borrow Simulator
- Credit Risk Assessment
- Explainable AI
- Smart Auto-Restructuring
- REST API architecture

## Technology

- Python
- FastAPI
- HTML / CSS / JavaScript
- Pandas
- NumPy
- Scikit-learn
- LightGBM
- Joblib

## Project Structure

- `main.py` — FastAPI backend
- `train.py` — model training
- `index.html` — frontend
- `style.css` — interface styling
- `app.js` — frontend logic
- `credit_risk_dataset.csv` — project dataset
- `models/` — trained model and preprocessing files
